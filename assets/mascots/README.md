# Mascot design sources

This folder holds editable mascot SVG artwork for Mèo cào media.

## Runtime assets

- `header-scout-cat.svg` — full-body cat standing above Main Header.
- `farewell-letter-cat.svg` — farewell cat carrying a thank-you letter.

## Tutorial fat explorer cats

Every tutorial slide has a deliberately different **fat manga-cat silhouette**.
They share a hand-held map but do **not** reuse a recoloured base cat:

1. `rose-scout-cat.svg` — round tabby with striped upright tail.
2. `cream-scout-cat.svg` — wide loaf cat with red scarf.
3. `lavender-scout-cat.svg` — seated pear-shaped cat in an explorer hat.
4. `ginger-scout-cat.svg` — chubby ginger cat with a satchel and curled tail.
5. `blue-scout-cat.svg` — round blue cat with map glasses and compass.
6. `mint-scout-cat.svg` — extra-wide mint cat with star bow.

The bookmarklet cannot reliably fetch external GitHub assets on arbitrary sites
because those sites may block external image/script requests. Runtime copies are
therefore inlined in `bookmark.js` and `render-header-proxy/bookmarklet.js`.
